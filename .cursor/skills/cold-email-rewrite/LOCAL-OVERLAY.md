# Customer Discovery Overlay — cold-email-rewrite

Read this file **after** `SKILL.md` when rewriting outreach in the **customer_discovery** repo.

## Role in this repo

Use for **second pass** work: humanize a draft, tighten length, compare against a `cold-email` first draft, or line-by-line critique.

## Context sources

Same as `cold-email/LOCAL-OVERLAY.md` — `config/product.yaml`, research briefs, evidence bundles, existing packs.

## Rewrite rules (customer discovery)

- Remove sales language, feature dumps, and invented proof points
- Keep discovery question; do not add product pitch unless user asks
- Target ~120–180 words for email body; flag if over 150 words without good reason
- Preserve evidence-backed personalization; cut generic "I saw your profile" openers
- When comparing two drafts, note which lines are stronger and why

## Prohibited actions

- No shell commands or Python scripts (upstream `scripts/` was intentionally excluded)
- No credential access or automation
- No live web search
